Sekcja 1

CyberRankR, czyli pakiet do priorytetyzacji zagrożeń cybernetycznych

Jest to paczka w języku R, której celem jest priorytetyzacja zagrożeń cybernetycznych metodami wielokryterialnej analizy decyzyjnej w środowisku rozmytym. Umożliwia pełny przebieg procesu analitycznego. Zaczynając od surowych danych incydentów sieciowych, poprzez wyznaczanie wag metodą BWM, aż na rankingu ataków za pomocą Fuzzy TOPSIS, Fuzzy VIKOR i Fuzzy WASPAS kończąc. Ma na celu sporządzić metaranking cyberzagrożeń.

Głównym wyzwaniem w analizie cyberzagrożeń jest to, że poszczególne ataki oceniane są subiektywnie. Ponadto, ich oceny są obarczone niepewnością wynikającą z niekompletnych danych i różnic w percepcji ryzyka. Pakiet CyberRankR rozwiązuje problem niepewności eksperckiej przez zastosowanie rozmytej logiki trójkątnej (TFN). Zamiast opierać się na jednej sztywnej ocenie, każde kryterium jest reprezentowane przez przedział (l, m, u), co pozwala modelować naturalną niepewność ludzkich osądów i budować odporne rankingi priorytetów.

Pakiet dedykowany jest analitykom bezpieczeństwa i decydentom IT, którzy potrzebują narzędzia umożliwiającego rzetelne porównanie typów ataków według wielu kryteriów jednocześnie, bez konieczności głębokiej znajomości matematyki rozmytej.

Problem

Subiektywne i niepewne oceny bezpieczeństwa dotyczące priorytetyzacji zagrożeń sieciowych.

Użytkownik

Badacze cyberbezpieczeństwa i zespoły informatyczne potrzebujące rzetelnego narzędzia rankingowego.

Wynik

Odporny na wahania eksperckie metaranking ataków: DDoS, Malware, Intrusion, wskazujący priorytety działań obronnych.

Sekcja 3

Rozmywanie danych, czyli fuzyfikacja.

Surowe wartości kryteriów są najpierw skalowane do skali Saaty'ego 1-9, a następnie każda wartość x jest zamieniana na Trójkątną Liczbę Rozmytą o strukturze (l, m, u) = (x-1, x, x+1), ograniczoną do przedziału [1,9].

Zasada działania: Ocena złożoności ataku wynosząca 7 (w skali Saaty'ego) jest interpretowana elastycznie jako przedział (6, 7, 8). Defuzzyfikacja centroidem: (l + 4m + u) / 6. Pozwala to absorować niepewność ekspercką bez utraty struktury porównawczej.

Sekcja 4

Wagi kryteriów

Wagi wyznaczono metodą BWM przy użyciu programowania liniowego. Dane panelowe wykazały anomaly jako kryterium najważniejsze i complexity jako najmniej ważne. Następnie porównane zostały pozostałe kryteria do tych wzorców na skali 1-9. Wskaźnik spójności CR < 0.10 potwierdza poprawność ocen.

Sekcja 5

Wyniki i stabilność (Meta-ranking)

Pakiet uruchamia równolegle trzy metody: Fuzzy TOPSIS, Fuzzy VIKOR i Fuzzy WASPAS, a następnie agreguje wyniki w jeden metaranking konsensusowy przy użyciu algorytmu dominacji i korelacji rang Spearmana.

Współczynnik bliskości CC

Im wyższe CC, tym bliżej ideału. Ranking: im wyższy wynik, tym lepiej.

VIKOR

Indeks kompromisu Q

Im niższe Q, tym lepsza alternatywa (mniejszy kompromis).

WASPAS

Wynik łączny Q

Kombinacja sumy ważonej (WSM) i iloczynu ważonego (WPM), λ = 0.5.

Sekcja 6

Jak odtworzyć analizę?

Ta sekcja pozwala badaczom zweryfikować obliczenia prezentowane na stronie przy użyciu realnego zbioru danych dołączonego do pakietu: 

# 1. Instalacja pakietu bezpośrednio z repozytorium GitHub
devtools::install_github("BeatryczePilat/CyberRankR")
library(CyberRankR)

# 2. Wczytanie wbudowanego zbioru danych incydentów cyberbezpieczeństwa
data("cyber_expert_panel")

# 3. Definicja struktury kryteriów i ich kierunków optymalizacji
typy_kryteriow <- c(
  severity   = "max",
  anomaly    = "min",
  complexity = "max",
  impact     = "max",
  stealth    = "min"
)

# 4. Transformacja danych do rozmytej macierzy decyzyjnej (TFN)
macierz_rozmyta <- przygotuj_dane_mcda(
  dane               = cyber_expert_panel,
  skladnia           = "
    severity   =~ crit_severity;
    anomaly    =~ crit_anomaly;
    complexity =~ crit_complexity;
    impact     =~ crit_impact;
    stealth    =~ crit_stealth
  ",
  kolumna_alternatyw = "Alternative"
)

# 5. Wyznaczenie wag kryteriów metodą BWM (programowanie liniowe)
wynik_bwm <- oblicz_wagi_bwm(
  nazwy_kryteriow     = c("severity", "anomaly", "complexity", "impact", "stealth"),
  najlepsze_do_innych = c(3, 1, 7, 2, 4),
  inne_do_najgorszego = c(4, 7, 1, 5, 3)
)
wagi_rozmyte <- rep(wynik_bwm$wagi_kryteriow, each = 3)

# 6. Uruchomienie meta-rankingu (TOPSIS + VIKOR + WASPAS)
meta_wynik <- rozmyty_meta_ranking(
  macierz_decyzyjna = macierz_rozmyta,
  typy_kryteriow    = typy_kryteriow,
  wagi              = wagi_rozmyte
)

# 7. Wizualizacja i tabele APA
plot(rozmyty_topsis(macierz_rozmyta, typy_kryteriow, wagi_rozmyte))
plot(rozmyty_vikor(macierz_rozmyta, typy_kryteriow, wagi_rozmyte))
tabela_apa(meta_wynik)
Skrót: Cały pipeline można uruchomić jedną komendą: cyber() # wagi BWM (domyślnie) lub cyber(wagi = "entropia")
